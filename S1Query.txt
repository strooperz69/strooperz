You can remove `| limit 200`. The Event Search time picker already sets the window (Last 24 hours). `limit` does not mean “24 hours.” It means “stop after this many **rows**,” and after this query those rows are **files**, not Copilot prompts. Leave the picker on 24 hours and drop the limit if you want every file in that window. The console may still cap how many rows it draws (often a few thousand). If the UI says results were truncated, export or `| group` instead of listing every row.

What each line does:

**`tag != 'logVolume'`**  
SDL writes extra accounting rows under the same source (`tag = 'logVolume'`). They are ingest meters, not Copilot. This drops them so a count is real file access, not billing noise.

**`dataSource.name = 'Microsoft Copilot'`**  
Only that lake source. Other sources (Netskope, EDR, the old `Azure` hub name) stay out.

**`LLMEventData.AccessedResources[*].Name = *`**  
Keep events that have at least one grounding file name. `[*]` is the wildcard S1 allows on that array. `[0]`, `[5]`, and a bare `.Name` are viewer labels, not something PowerQuery can loop. `= *` means “this field is present,” not a search for the character `*`.

**`| let names = LLMEventData.AccessedResources[*].Name`**  
Copy the whole name list for this event into `names` (all files, not just the first).

**`| let actions = LLMEventData.AccessedResources[*].Action`**  
Same for actions (`Read`, `Create`, `Modify`) in the **same order** as `names`. File 1’s action is slot 1, file 2’s is slot 2.

**`| let pair = names.zip(actions, func(n, a) -> format("%s~~~%s", n, a))`**  
Walk both lists together. Each file becomes one string, `FileName~~~Action`. `zip` is what keeps name and action on the same file. `~~~` is only glue. Do not use `||` here: `|` is regex, and `split` would chop the string into letters.

**`| let row = pair.expand()`**  
Turn that list into **one result row per file**. A prompt that touched five files becomes five rows. Same timestamp, five names. Empty lists drop the event.

**`| let parts = row.split('~~~')`**  
Break the glued string into two pieces: `[FileName, Action]`.

**`| let FileName = parts.get(0)`**  
First piece → `FileName`.

**`| let Action = parts.get(1)`**  
Second piece → `Action`.

**`| filter FileName = *`**  
Drop rows where `FileName` is missing.

**`| filter !isempty(FileName)`**  
Drop rows where it is present but blank (`""`).

**`| filter !(FileName = 'null')`**  
Drop rows where the value is the text `null` (not the same as a missing field).

**`| columns timestamp, FileName, Action`**  
Show only those three columns. After `columns`, other fields are gone.

**`| sort -timestamp`**  
Newest first. `-` is descending.

**`| limit 200`**  
Safety cap we used while testing so Event Search would not try to render a huge explode. **Not required** for a 24-hour review. Remove it:

```
tag != 'logVolume'
dataSource.name = 'Microsoft Copilot'
LLMEventData.AccessedResources[*].Name = *
| let names = LLMEventData.AccessedResources[*].Name
| let actions = LLMEventData.AccessedResources[*].Action
| let pair = names.zip(actions, func(n, a) -> format("%s~~~%s", n, a))
| let row = pair.expand()
| let parts = row.split('~~~')
| let FileName = parts.get(0)
| let Action = parts.get(1)
| filter FileName = *
| filter !isempty(FileName)
| filter !(FileName = 'null')
| columns timestamp, FileName, Action
| sort -timestamp
```

Set the picker to 24 hours. Do not put a time expression in the query; the UI already applies it.

This is still “Copilot accessed this file.” Adding the user does **not** split the file rank if you only `group` by `FileName`. The list query below is one row per access (file + user + action). The second query is unique files, with users attached.

    OR FileName contains 'SPI'

`contains` is case-insensitive (`cui` matches `CUI`). Short tokens, especially **SPI**, will match inside longer names (`Hospital` does not, but `DISPIRIT` / `SPIFF` would). If that noise shows up, switch those lines to a word-style regex, with S1’s double backslashes:

```
FileName matches '\\bCUI\\b'
OR FileName matches '\\bCHRI\\b'
OR FileName matches '\\bSPI\\b'
OR FileName matches '\\bAMBER\\b'
```

Add keywords with another `OR FileName contains 'FOUO'`. If the marking lives in the path instead of the title, zip `SiteUrl` as a third `~~~` piece and run the same `contains` on that field too.

This is **name-based**. It does not read Purview `SensitivityLabelId`. A CUI file named `Q3-budget.xlsx` will not hit until you join labels.

The broken piece is not `AccessedResources[*].Name`. That wildcard is unchanged from the queries that already work.

The new line was:

```
| let App = (AppIdentity = * ? AppIdentity : (LLMEventData.AppIdentity = * ? ...
```

`= *` means “field is present.” That is legal in the **first** filter (and you got away with it on `| filter FileName = *`). Inside `let` / `? :`, S1 treats `*` the same way as `| columns *` and throws **doesn't understand [*], try enclosing in quotes**. The `[*]` in the error is that presence star, not the array wildcard.

You also do not need `Action` or `zip` for this count. Explode names only, then take `AppIdentity` from the parent event (it copies onto every file row).

```
tag != 'logVolume'
dataSource.name = 'Microsoft Copilot'
LLMEventData.AccessedResources[*].Name = *
| let names = LLMEventData.AccessedResources[*].Name
| let FileName = names.expand()
| let App = AppIdentity ? AppIdentity : LLMEventData.AppIdentity
| filter FileName = *
| filter !isempty(FileName)
| filter !(FileName = 'null')
| filter !isempty(App)
| group n=count(), files=estimate_distinct(FileName) by App
| sort -n
```

If `App` is empty, open one event and put the real field in the `let App =` line only, for example `unmapped.AppIdentity`. Do not write `= *` inside `let`.

`n` = file-access events per app. `files` = distinct file names per app. Time picker still sets the window.
```
| group n=count() by App, FileName
| sort -n
```

`n` = how many times that app grounded on that name. `files` = how many different names that app touched. Use `files` when you want “count of files,” `n` when you want “count of accesses.”

Same file explode as the AppIdentity query. `City` and `CountryCode` sit on the **event**, so they copy onto every file row. Do not put `= *` inside `let`.

```
tag != 'logVolume'
dataSource.name = 'Microsoft Copilot'
LLMEventData.AccessedResources[*].Name = *
| let names = LLMEventData.AccessedResources[*].Name
| let FileName = names.expand()
| let City = CloudAppEvents.City
| let Country = CloudAppEvents.CountryCode

| filter !isempty(FileName)
| filter !(FileName = 'null')
| filter !isempty(City)

```

`n` = file-access events from that city/country. `files` = distinct names. Time picker still sets the window.

If `City` / `Country` come back empty, the parser may have flattened them (`City`, `unmapped.City`). Open one event and put the exact names in the two `let` lines.

To keep rows with a country but no city, drop `| filter !isempty(City)`.
