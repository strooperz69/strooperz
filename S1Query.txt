`[*]` is the only accessor PowerQuery accepts on that flattened array. `[0]`, `[5]`, and the unindexed `.Name` path are display keys, not query fields.

`group by LLMEventData.AccessedResources[*].Name` still usually returns **one cell per event**, JSON-wrapped, like `["a.docx","b.docx"]`. It is not one row per file yet.

Explode that wildcard into rows:

```
tag != 'logVolume'
dataSource.name = 'Microsoft Copilot'
LLMEventData.AccessedResources[*].Name = *
| let names = LLMEventData.AccessedResources[*].Name
| let FileName = names.expand()
| columns timestamp, FileName
| sort -timestamp
| limit 200
```

If `FileName` is still a JSON array string, parse then explode:

```
tag != 'logVolume'
dataSource.name = 'Microsoft Copilot'
LLMEventData.AccessedResources[*].Name = *
| let names = array_from_json(LLMEventData.AccessedResources[*].Name)
| let FileName = names.expand()
| columns timestamp, FileName
| sort -timestamp
| limit 200
```

Keep `Name` lined up with `Action`:

```
tag != 'logVolume'
dataSource.name = 'Microsoft Copilot'
LLMEventData.AccessedResources[*].Name = *
| let names = LLMEventData.AccessedResources[*].Name
| let actions = LLMEventData.AccessedResources[*].Action
| let pair = names.zip(actions, func(n, a) -> format("%s||%s", n, a))
| let row = pair.expand()
| columns timestamp, row
| sort -timestamp
| limit 200
```

If `names` is a string, wrap both in `array_from_json(...)` before `zip`.

A five-file prompt should produce **five rows**. After `expand()`, `count()` is files, not Copilot turns.
